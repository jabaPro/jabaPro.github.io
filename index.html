¡Bienvenidos/as!

Este sitio es una página de prueba creada para mostrar el trabajo con Git y GitHub en clase.
Aquí puedes practicar cambios, commits y ver tus actualizaciones en vivo.

Instrucciones para estudiantes

  • Haz un fork de este repositorio.
  • Clona tu fork a tu equipo (git clone ...).
  • Modifica este archivo index.html y añade tu nombre o cualquier mensaje de prueba.
  • Realiza un commit (git commit -am "Mi cambio").
  • Haz push a tu repositorio en GitHub.
  • Haz un pull request a este repositorio para compartir tu cambio.

Puedes editar estilos, textos, agregar imágenes, lo que desees para practicar.
